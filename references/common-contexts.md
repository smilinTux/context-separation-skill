# Common Context Patterns

## Business Contexts

### Client/Project Updates
**Appropriate:**
- Revenue milestones, security fixes, deployment status
- Agent workstream progress, customer acquisition
- Technical platform updates, timeline changes

**Inappropriate:**
- Personal account setup, social media requests
- Infrastructure issues unrelated to client project
- Website domain problems (unless client-specific)

### Trustee/Stakeholder Reports
**Appropriate:**
- Financial performance, risk assessments
- Strategic decisions, milestone achievements
- Competitive analysis, market opportunities

**Inappropriate:**
- Personal administrative tasks
- General infrastructure maintenance
- Social media account management

## Personal/Administrative Contexts

### Infrastructure Management
**Appropriate:**
- Server maintenance, DNS configuration
- Email setup, domain registration
- General system administration

**Inappropriate:**
- Client-specific technical updates
- Revenue/business performance data
- Stakeholder-sensitive information

### Social/Community Engagement  
**Appropriate:**
- Account claiming, community setup
- Social media strategy, content creation
- Personal branding, networking

**Inappropriate:**
- Business financial data
- Client confidential information
- Internal operational details

## Red Flag Phrases

### Personal in Business:
- "claim my account"
- "personal social media"  
- "my Moltbook/Twitter/etc"
- "set up my..."

### Infrastructure in Client:
- "server maintenance"
- "DNS configuration"
- "domain registration"
- "general system..."

### Off-topic in Focused:
- Multiple unrelated topics in one message
- Mixing personal requests with business updates
- Administrative tasks in strategic discussions

## Best Practices

1. **One context per message** - Don't mix topics
2. **When in doubt, go general** - Use main chat if unsure
3. **Consider the audience** - Would stakeholders find this relevant?
4. **Validate before posting** - Use check-context.sh
5. **Learn from violations** - Review patterns regularly
